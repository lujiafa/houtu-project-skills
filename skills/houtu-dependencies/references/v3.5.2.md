## Diff from v3.5.1

v3.5.2 是稳定性与 bug 修复版本，第三方依赖版本均不变。

### Bug 修复（14 项）

**Critical（9 项）：**
- `SimpleSession`: `addRole()`/`getRoles()` 误操作 permissions 而非 roles
- `JWTSessionRepository`: switch 缺少 break 导致 RSA/ECDSA 密钥被覆写
- `RedisSessionRepository`: String 与 Boolean 比较始终返回 false
- `NacosServiceContext`: 空值检查使用 `&&` 而非 `||` 导致 NPE
- `JedisConnectionFactoryBeanUtils`: 误读 Lettuce 配置而非 Jedis 配置
- `JsonUtils`: 构造器自赋值 objectMapper，忽略注入实例
- `ValidationHandlerExceptionResolverCustomizer`: 分号条件反转
- `SecurityWatchAspect`: `m.put()` 写入错误 map 导致数据丢失
- `RedisLockAspect`: `tryLock()` 返回值被忽略

**High（2 项）：**
- `FeignDelegateDecoder`: `type.getClass()` 检查 Type 对象而非实际返回类型
- `HttpClients`: 移除 System.out.println 调试语句

**Low（3 项）：** 拼写修正（'nust' → 'must', 'paramater' → 'parameter'）、移除重复 `.withCharset()` 调用

### 功能增强

- **@Lock SpEL 支持**：`key` 参数新增 `#` 前缀 SpEL 表达式模式，支持嵌套属性访问（如 `key = "#user.id"`）
- **RedisLockAspect 性能优化**：参数名索引与 SpEL Expression 解析结果均使用 ConcurrentHashMap 缓存

### 移除

- 删除 `@ReqMonitor`、`@RpcMonitor` 注解（无对应 Aspect 实现，属于无功能死代码）

### 其他

- `DATA_ALREADY_EXIST` 错误码修正为 42（v3.5.1 中与 `DATA_NOT_EXIST` 同为 41）
- 完成 Jakarta 迁移：`javax.mail` → `jakarta.mail`（angus-mail）

## API Differences

- **@Lock key 三种模式**：空字符串 → `className.methodName`；不带 `#` → 参数名匹配；`#` 前缀 → SpEL 表达式（v3.5.2 新增）
- All other module APIs documented in module-*.md files apply to this version
