### Redis Configuration Path

```yaml
# v2.7.x:
spring:
  redis:
    host: localhost
    port: 6379

# v3.5.x:
spring:
  data:
    redis:
      host: localhost
      port: 6379
```

## Module API Differences

### houtu-cache (@Lock)

`@Lock` key 仅支持两种模式：空字符串 → `className.methodName`；非空 → 参数名精确匹配。**不支持 SpEL 表达式**（v2.7.3 / v3.5.2 新增支持）。

### houtu-web-swagger

SpringDoc artifact: `springdoc-openapi-ui` 1.8.0（非 `springdoc-openapi-starter-webmvc-ui`）

### Redis 配置路径

```yaml
spring:
  redis:                               # 注意：v2.7.x 无 data 层级
    host: localhost
    port: 6379
```

### 其他

所有 module-*.md 中的通用 API 均适用，但需注意：
1. 使用 `javax.*` imports（非 `jakarta.*`）
2. Redis 配置路径为 `spring.redis.*`（非 `spring.data.redis.*`）
3. SpringDoc 为 `springdoc-openapi-ui`（非 `springdoc-openapi-starter-webmvc-ui`）
