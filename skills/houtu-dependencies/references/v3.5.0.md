## Diff from v3.5.1

**Only difference:** SCA `2023.0.1.2` (not `2025.0.0.0`).

### Nacos Config — uses bootstrap.yml (NOT spring.config.import)

SCA `2023.0.1.2` < `2023.0.1.3`, so Nacos config still loads via **bootstrap**:

```yaml
# bootstrap.yml (NOT application.yml)
spring:
  cloud:
    nacos:
      config:
        server-addr: 127.0.0.1:8848
```

Requires `spring-cloud-starter-bootstrap` dependency.

## Module API Differences

### houtu-cache (@Lock)

`@Lock` key only supports two modes: empty string → `className.methodName`; non-empty → exact parameter name match. **Does not support SpEL expressions**.

### houtu-web-swagger

SpringDoc artifact: `springdoc-openapi-starter-webmvc-ui` 2.8.9

### Redis Configuration Path

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
```
