## Version-Specific: Nacos Config

SCA `2025.0.0.0` — uses `spring.config.import` (**NOT** bootstrap.yml):

```yaml
spring:
  config:
    import:
      - nacos:application.yml
  cloud:
    nacos:
      config:
        server-addr: 127.0.0.1:8848
```

## Module API Differences

### houtu-cache (@Lock)

`@Lock` key 仅支持两种模式：空字符串 → `className.methodName`；非空 → 参数名精确匹配。**不支持 SpEL 表达式**（v3.5.2 新增）。

### houtu-web-swagger

SpringDoc artifact: `springdoc-openapi-starter-webmvc-ui` 2.8.9

### Redis 配置路径

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
```

### 其他

所有 module-*.md 中的通用 API 均适用于本版本。
