## Version-Specific: Nacos Config

SCA `2025.0.0.0` — uses `spring.config.import` (**NOT** bootstrap.yml):

```yaml
spring:
  config:
    import:
      - nacos:application.yml
  cloud:
    nacos:
      config:
        server-addr: 127.0.0.1:8848
```

## Module API Differences

### houtu-cache (@Lock)

`@Lock` key only supports two modes: empty string → `className.methodName`; non-empty → exact parameter name match. **Does not support SpEL expressions** (added support in v3.5.2 / v2.7.3).

### houtu-web-swagger

SpringDoc artifact: `springdoc-openapi-starter-webmvc-ui` 2.8.9

### Redis Configuration Path

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
```

All generic APIs in module-*.md apply to this version.
