## Diff from v2.7.2

v2.7.3 is a code quality, performance, and security optimization release; third-party dependency versions remain unchanged.

### Feature Enhancements

- **@Lock SpEL support**: the `key` parameter now supports a `#`-prefixed SpEL expression mode with nested property access (e.g., `key = "#user.id"`)
- **RedisLockAspect performance optimization**: parameter name indexes and SpEL Expression parse results are now cached using ConcurrentHashMap

### Code Quality Improvements

**Thread Safety:**
- `SessionContext`: added `volatile` to the `INSTANCE` field, adopted double-checked locking for singleton initialization
- `JsonUtils`: added `volatile` to the `nonNullObjectMapper` and `objectMapper` static fields

**Performance Optimization:**
- Removed all `parallelStream()` calls, replaced with `stream()` (affects RedisSessionRepository, SecurityWatchAspect, XssConstraintValidator)

**Security Hardening:**
- `XssConstraintValidator`: XSS pattern list changed to `Collections.unmodifiableList()` immutable collection, added null value check
- `SecurityWatchAspect`: corrected logical operator precedence in field filtering (added explicit parentheses)

**Compatibility:**
- Replaced deprecated `clazz.newInstance()` with `clazz.getDeclaredConstructor().newInstance()` (Java 9+ compatible)

### Removals

- Removed `@ReqMonitor` and `@RpcMonitor` annotations (no corresponding Aspect implementation; non-functional dead code)

### @AccessLog — v2.7.3 consistent with v3.5.x

The `@AccessLog` in v2.7.3 uses `requestBody` and supports `requestHeaders`, fully consistent with v3.5.x.

## Module API Differences

### houtu-cache (@Lock)

The `@Lock` key in v2.7.3 supports three modes:
- Empty string → `className.methodName`
- Without `#` → exact parameter name match (e.g., `key = "orderId"`)
- `#` prefix → **SpEL expression** (added in v2.7.3), supports nested property access

```java
// SpEL: resolve lock key from nested properties of method parameters
@Lock(prefix = "user:", key = "#user.id")
public void updateUser(User user) { ... }

@Lock(prefix = "vip:", key = "#order.customer.vipId")
public void processVipOrder(Order order) { ... }
```

When the SpEL expression result is null, an AssertionError is thrown. Non-CharSequence types are serialized to the lock key via `JsonUtils.toString()`.
