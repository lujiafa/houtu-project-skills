## Diff from v2.7.2

v2.7.3 是代码质量、性能与安全性优化版本，第三方依赖版本均不变。

### 功能增强

- **@Lock SpEL 支持**：`key` 参数新增 `#` 前缀 SpEL 表达式模式，支持嵌套属性访问（如 `key = "#user.id"`）
- **RedisLockAspect 性能优化**：参数名索引与 SpEL Expression 解析结果均使用 ConcurrentHashMap 缓存

### 代码质量改进

**线程安全：**
- `SessionContext`: `INSTANCE` 字段添加 `volatile`，采用双重检查锁单例初始化
- `JsonUtils`: `nonNullObjectMapper` 和 `objectMapper` 静态字段添加 `volatile`

**性能优化：**
- 全面移除 `parallelStream()` 调用，改用 `stream()`（涉及 RedisSessionRepository、SecurityWatchAspect、XssConstraintValidator）

**安全加固：**
- `XssConstraintValidator`: XSS 模式列表改为 `Collections.unmodifiableList()` 不可变集合，增加 null 值检查
- `SecurityWatchAspect`: 修正字段过滤中的逻辑运算符优先级（添加显式括号）

**兼容性：**
- 替换已弃用的 `clazz.newInstance()` 为 `clazz.getDeclaredConstructor().newInstance()`（Java 9+ 兼容）

### 移除

- 删除 `@ReqMonitor`、`@RpcMonitor` 注解（无对应 Aspect 实现，属于无功能死代码）

### @AccessLog — v2.7.3 与 v3.5.x 一致

v2.7.3 的 `@AccessLog` 使用 `requestBody` 且支持 `requestHeaders`，与 v3.5.x 完全一致。

## Module API Differences

### houtu-cache (@Lock)

v2.7.3 的 `@Lock` key 支持三种模式：
- 空字符串 → `className.methodName`
- 不带 `#` → 参数名精确匹配（如 `key = "orderId"`）
- `#` 前缀 → **SpEL 表达式**（v2.7.3 新增），支持嵌套属性访问

```java
// SpEL: 从方法参数的嵌套属性解析锁键
@Lock(prefix = "user:", key = "#user.id")
public void updateUser(User user) { ... }

@Lock(prefix = "vip:", key = "#order.customer.vipId")
public void processVipOrder(Order order) { ... }
```

SpEL 表达式结果为 null 时抛出 AssertionError。非 CharSequence 类型通过 `JsonUtils.toString()` 序列化为锁键。

### houtu-web-swagger

SpringDoc artifact: `springdoc-openapi-ui` 1.8.0（非 `springdoc-openapi-starter-webmvc-ui`）

### Redis 配置路径
