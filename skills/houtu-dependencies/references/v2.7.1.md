## Module API Differences

### houtu-cache (@Lock)

`@Lock` key only supports two modes: empty string → `className.methodName`; non-empty → exact parameter name match. **Does not support SpEL expressions**.

### houtu-web-swagger

SpringDoc artifact: `springdoc-openapi-ui` 1.8.0 (not `springdoc-openapi-starter-webmvc-ui`)

### Redis Configuration Path

```yaml
spring:
  redis:                               # Note: v2.7.x has no `data` hierarchy
    host: localhost
    port: 6379
```

### Other

All generic APIs in module-*.md apply, but note:
1. Use `javax.*` imports (not `jakarta.*`)
2. Redis config path is `spring.redis.*` (not `spring.data.redis.*`)
3. SpringDoc is `springdoc-openapi-ui` (not `springdoc-openapi-starter-webmvc-ui`)
