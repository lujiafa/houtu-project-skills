| JDK | 1.8 | 17 |

### @AccessLog — v2.7.1 与 v3.5.x 一致

v2.7.1 的 `@AccessLog` 使用 `requestBody` 且支持 `requestHeaders`，与 v3.5.x 完全一致。

### Redis Configuration Path

```yaml

  redis:
    host: localhost
    port: 6379

# v3.5.x:
spring:
  data:
    redis:
      host: localhost
      port: 6379
```

## APIs

All module APIs in module-*.md files apply, except:
1. Redis config path: `spring.redis.*` (not `spring.data.redis.*`)
2. Use `javax.*` imports instead of `jakarta.*`
3. SpringDoc: `springdoc-openapi-ui` (not `springdoc-openapi-starter-webmvc-ui`)
